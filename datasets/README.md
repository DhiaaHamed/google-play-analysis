# Source datasets

Both CSV files are preserved unchanged from the supplied DataCamp project archive.

- **apps.csv**: app name, category, rating, review count, reported size, install band, free/paid type, listed price, content rating, genres, last update and version fields. The unnamed first column is a saved index.
- **user_reviews.csv**: app name, preprocessed review text, supplied sentiment label, polarity and subjectivity.

These are historical sample data, not a current store inventory. Missing values, repeated review records and some encoding artifacts are present. Cleaning, join coverage and limitations are documented in the main notebook. Source-data rights remain with their respective owners.
